# AGENTS.md

## Project
Move To Improve is a static one-page website built with HTML, CSS, and JavaScript.

## Development guidelines
- Keep dependencies to a minimum.
- Prefer existing CSS variables for colours.
- Prefer defined fonts.
- Ask before adding aditional colours.
- Maintain responsive behaviour down to mobile sizes.
- Do not introduce frameworks unless explicitly requested.
- Keep accessibility attributes intact.

## Git workflow
- Do not commit changes directly to main unless explicitly asked.
- Create a separate branch for changes by default.
- For larger changes, offer logical commit stages before merging to main.

## Styling
- Follow the Move To Improve brand identity.
- The brand identity can be found in the  Movember 2026 shared Google Drive folder. 
- Reuse existing spacing, radius, and colour variables.
- Avoid duplicating CSS rules where possible.

## Testing
- Check desktop and mobile layouts after CSS changes.
- Check for horizontal overflow at mobile widths.
